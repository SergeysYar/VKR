# Инструкция по запуску VKR PointCloud Suite

Проект запускается в Windows через `uv` и Streamlit. Рекомендуемый режим —
`tabs`: единое приложение с вкладками генерации/размещения и анализа облаков
точек.

## 1. Что требуется установить

- Windows 10/11;
- Python 3.12 или новее;
- `uv`;
- доступ к интернету при первой установке зависимостей.

Проверка из PowerShell:

```powershell
python --version
uv --version
```

Если команда `uv` не найдена, установите его по официальной инструкции и
перезапустите PowerShell. После установки команда `uv` должна быть доступна
в `PATH`.

## 2. Первый запуск вручную

Откройте PowerShell и перейдите в каталог проекта:

```powershell
cd C:\_Work\VKR
```

Создайте виртуальное окружение и установите зависимости из `pyproject.toml` и
`uv.lock`:

```powershell
uv venv .venv
uv sync --project .
```

В проект входят, в частности, Streamlit, PyTorch, Open3D, Plotly, NumPy,
Pandas и библиотеки для работы с облаками точек. Установка может занять время
и потребовать несколько гигабайт свободного места.

## 3. Запуск через PowerShell-скрипт

Основная команда запуска:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_showcase_uv.ps1 -App tabs -Port 8513
```

Скрипт выполняет следующие действия:

1. определяет корень проекта относительно собственного расположения;
2. создаёт `.venv`, если его ещё нет;
3. выполняет `uv sync`, если не передан `-SkipSync`;
4. запускает выбранное Streamlit-приложение;
5. использует локальный `.uv-cache` для кэша `uv`.

После запуска откройте в браузере:

```text
http://localhost:8513
```

Чтобы остановить приложение, вернитесь в окно PowerShell и нажмите `Ctrl+C`.

## 4. Режимы приложения

Параметр `-App` определяет запускаемый файл:

| Режим | Назначение |
|---|---|
| `tabs` | Рекомендуемый интерфейс с двумя вкладками. |
| `builder` | Только генерация сцены, LiDAR-облака и размещение объектов. |
| `analysis` | Только анализ уже подготовленного облака точек. |
| `showcase` | Старая монолитная версия интерфейса. |

Примеры:

```powershell
# Рекомендуемый режим
powershell -ExecutionPolicy Bypass -File .\run_showcase_uv.ps1 -App tabs -Port 8513

# Генератор и размещение
powershell -ExecutionPolicy Bypass -File .\run_showcase_uv.ps1 -App builder -Port 8514

# Анализ готовых облаков
powershell -ExecutionPolicy Bypass -File .\run_showcase_uv.ps1 -App analysis -Port 8515

# Если зависимости уже установлены
powershell -ExecutionPolicy Bypass -File .\run_showcase_uv.ps1 -App tabs -Port 8513 -SkipSync
```

В текущем скрипте также доступны дополнительные режимы модулей:
`industrial`, `lidar`, `recognition`, `segmentation`, `reconstruction`.

## 5. Запуск двойным щелчком через BAT-файл

В корне проекта добавлен файл `run_project.bat`. Он вызывает тот же
PowerShell-скрипт, поэтому отдельная активация `.venv` не требуется.

### Самый простой запуск

Дважды щёлкните `run_project.bat`. Будет запущен режим `tabs` на порту
`8513`, затем откройте `http://localhost:8513`.

### Запуск из PowerShell или cmd

```text
run_project.bat
run_project.bat tabs 8513
run_project.bat builder 8514
run_project.bat analysis 8515 SkipSync
```

Параметр `SkipSync` удобно использовать после успешной первой установки,
чтобы не выполнять синхронизацию зависимостей при каждом запуске.

BAT-файл поддерживает и исходный стиль параметров PowerShell:

```text
run_project.bat -App tabs -Port 8513 -SkipSync
```

Если приложение завершилось с ошибкой, окно BAT не закроется сразу: код ошибки
будет показан в окне консоли. При двойном щелчке это позволяет прочитать
сообщение.

## 6. Прямой запуск без PowerShell-скрипта

Этот вариант нужен в основном для диагностики:

```powershell
cd C:\_Work\VKR
uv run --project . streamlit run lesson5/factory_tabs_app.py --server.headless true --server.port 8513
```

Для другого интерфейса замените путь к файлу:

```text
lesson5/factory_synthetic_builder_app.py
lesson5/factory_analysis_app.py
lesson5/factory_showcase_app.py
```

## 7. Рекомендуемый пользовательский сценарий

1. Запустить `run_project.bat`.
2. Открыть `http://localhost:8513`.
3. Во вкладке конструктора сгенерировать сцену и LiDAR-облако.
4. Добавить PLY-файлы объектов и выполнить их размещение.
5. Сохранить объединённое облако.
6. Во вкладке анализа загрузить готовое облако.
7. При необходимости выполнить распознавание, сегментацию,
   реконструкцию поверхности и экспорт OBJ.

## 8. Частые проблемы

### PowerShell блокирует `.ps1`

Используйте запуск с обходом политики, который уже включён в BAT:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_showcase_uv.ps1
```

### Порт занят

Запустите приложение на другом порту, например:

```text
run_project.bat tabs 8514
```

Затем откройте `http://localhost:8514`.

### Зависимости установлены не полностью

Повторите синхронизацию:

```powershell
cd C:\_Work\VKR
uv sync --project .
```

Не используйте `SkipSync`, пока установка не завершилась успешно.

### TensorBoard не найден

Выполните:

```powershell
uv sync --project .
```

При необходимости отдельно установите пакет:

```powershell
uv pip install tensorboard
```

### Недостаточно памяти

Для демонстрации используйте умеренную плотность LiDAR и уменьшите размер
батча при обучении на CPU. Плотные облака и запуск PyTorch могут потребовать
значительный объём RAM.

## 9. Структура запуска

- `pyproject.toml` — список зависимостей и требования к Python;
- `uv.lock` — зафиксированные версии зависимостей;
- `.venv` — локальное виртуальное окружение;
- `run_showcase_uv.ps1` — основной скрипт запуска;
- `run_project.bat` — запуск двойным щелчком или из cmd;
- `lesson5/factory_tabs_app.py` — рекомендуемый Streamlit-интерфейс;
- `lesson5/factory_showcase_pipeline.py` — основная логика обработки.
