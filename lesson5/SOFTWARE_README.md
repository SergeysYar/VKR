# ПО для классификации инженерных объектов (русский интерфейс)

Основное приложение: `factory_showcase_app.py`.

## Что есть в интерфейсе

1. Блок генерации завода  
- генерация завода по параметрам;  
- настройка плотности облака LiDAR;  
- либо загрузка готового облака завода (`.ply` + опционально JSON метаданных);  
- сохранение облака завода и метаданных.

2. Блок размещения объектов  
- выбор облака завода;  
- добавление объектов по одному (конкретный `.ply` в очередь);  
- размещение очереди объектов внутри завода;  
- сохранение комбинированного облака и отчёта по объектам в комнатах.

3. Блок распознавания  
- распознавание объектов в выбранном облаке точек по `.ckpt`;  
- загрузка папки с облаками конкретного объекта и дообучение модели;  
- сохранение весов по типам объектов в `D:\vesa\...`.

4. Блок сегментации  
- после распознавания выбирается объект;  
- подключаются веса сегментации (автопоиск из `D:\vesa\<тип>\checkpoints`).

5. Блок восстановления поверхности  
- запуск восстановления по сегментированным частям;  
- настройка параметров восстановления.

## Запуск через uv (рекомендуется)

Из корня репозитория `C:\_Work\VKR`:

```powershell
uv venv .venv
uv sync
uv run streamlit run lesson5/factory_showcase_app.py
```

Или скриптом:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_showcase_uv.ps1
```

## Важные файлы

- `lesson5/factory_showcase_app.py` — основной русскоязычный UI.
- `lesson5/factory_showcase_pipeline.py` — backend-пайплайн (генерация, размещение, распознавание, дообучение, сегментация, восстановление).
- `lesson5/ui_app.py` — старый интерфейс PointNet (оставлен отдельно).
